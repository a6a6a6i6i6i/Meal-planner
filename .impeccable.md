# Impeccable Design Context

## Design Context

### Users
Personal daily tool — the owner opens it themselves to plan the week's meals and keep macros on track. Context is quick, habitual, and low-stress: a few minutes on Sunday evening or Monday morning. The job is: see the whole week at a glance, slot in meals, and know instantly if macros are on target. Speed and clarity matter more than onboarding polish.

### Brand Personality
Warm · Playful · Delightful

This is a personal tool that should feel like a well-designed kitchen notebook — not a clinical fitness tracker. The interface should spark a little joy every time it opens: inviting cream canvas, bright brand-color accents, and micro-details that reward attention.

### Aesthetic Direction
- **Design system source:** `DESIGN.md` — Clay.com-inspired. Cream canvas (`#fffaf0`), warm ink type, and a 6-color saturated brand palette (pink, teal, lavender, peach, ochre, mint).
- **Typography:** Inter at 400 / 500 / 600. Display sizes use `font-medium tracking-tight`. Labels use `uppercase tracking-[0.1em]` (caption-uppercase style).
- **Border radius:** Generous — 12px buttons/inputs (`rounded-lg`), 16px content cards (`rounded-2xl`), 24px feature elements (`rounded-3xl`), pill for badges (`rounded-full`).
- **Color roles:**
  - Calories → brand-ochre `#e8b94a`
  - Protein → brand-pink `#ff4d8b`
  - Fat → brand-mint `#a4d4c5`
  - Carbs → brand-peach `#ffb084`
  - Swap suggestions → brand-lavender `#b8a4ed`
  - Today accent → brand-peach border + brand-ochre date number
- **Theme:** Light mode only. The cream canvas is the brand's warmth — dark mode is not in scope.
- **Anti-references:** Clinical white + cool-gray data dashboards. Nothing that feels like a hospital form or a spreadsheet.

### Design Principles
1. **Cream-first warmth** — `bg-background` is always the cream canvas (#fffaf0). Never use pure white or cool gray as the page floor.
2. **Brand colors carry meaning** — each macro has its own brand color (ochre/pink/mint/peach). Keep these consistent everywhere macros appear: bars, pills, badges.
3. **Typography has two modes** — Inter 500 `tracking-tight` for readable display text; Inter 600 `uppercase tracking-[0.1em]` for small labels and section markers.
4. **Cards breathe** — product-mockup cards use `bg-background border border-border rounded-2xl` with generous padding. No heavy shadows; depth comes from color contrast against the cream floor.
5. **Delight in the details** — pill badges with dot indicators, lavender swap cards, ochre today-date highlight. Small touches that make a personal tool feel crafted.
